To Start:
  Run: pip install -r requirements.txt
  
For the Main Code:
  To get news for AAPL from 2017 - 2024
    Run: python fetch_news_gdelt.py 

  To Analyze the news from GDELT using FinBERT
    Run: python analyze_sentiment_score.py

  For the main program:
    Run: python stock_prediction.py

For Independent Research:
  Run: python fuzzy_logic.py
